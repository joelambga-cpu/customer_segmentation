# Customer Segmentation Project

## Descrizione
Questo progetto mostra la **segmentazione clienti** tramite analisi dati.  
Utilizza **pandas** per la manipolazione dei dati, **scikit-learn** per il clustering e **matplotlib/seaborn** per la visualizzazione.

Il progetto analizza un dataset fittizio di clienti italiani, segmentandoli in cluster basati su età, reddito mensile e spesa mensile.
